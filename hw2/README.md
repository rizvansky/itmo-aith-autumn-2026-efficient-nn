# Super-Convergence: эксперимент на MNIST

Этот код повторяет эксперимент с MNIST и LeNet из статьи Leslie Smith и Nicholay Topin [Super-Convergence: Very Fast Training of Neural Networks Using Large Learning Rates](https://arxiv.org/abs/1708.07120). Мы сравниваем быстрое обучение с расписанием 1cycle и обычное обучение с убывающим learning rate.

`train.py` запускает три варианта на одной сети и одних данных:

- `one_cycle`: 12 эпох, learning rate от 0.01 до 0.1, обратно до 0.01 и затем до 0.0001, momentum от 0.95 до 0.8 и обратно;
- `inverse_12`: обычное расписание на 12 эпох, сравнение при одинаковом числе эпох;
- `inverse_85`: обычное расписание на 85 эпох, как в таблице 2 статьи.

Размер батча 512, weight decay 0.0005. Архитектура повторяет пример LeNet из Caffe: две свертки с max pooling, полносвязный слой на 500 нейронов и выход на 10 классов. Пиксели делятся на 256. Для bias learning rate вдвое выше, чем для весов.

В статье для 1cycle за 12 эпох получено 99.25%, а для обычного расписания за 85 эпох 99.03%. Эти числа не стоит ожидать с точностью до сотых процента: наш код использует PyTorch вместо Caffe. В статье не указано конечное значение learning rate для последних двух эпох, поэтому здесь оно задано равным 0.0001. Смысл эксперимента в сравнении точности и времени обучения при описанных настройках.

## Запуск

Нужен Python 3.10 или новее. На Mac с Apple Silicon:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python train.py
```

Скрипт сам выберет MPS, CUDA или CPU и скачает MNIST в `data/`. Чтобы повторить результаты отчета на пяти seed, запустите `python train.py --seeds 0 1 2 3 4`.

Каждый запуск создает новую папку в `results/`:

- `epochs.csv`: loss, точность на тесте, время обучения, learning rate и momentum последнего батча каждой эпохи;
- `summary.csv`: итоговая точность и время каждого варианта;
- `environment.json`: версии Python и PyTorch, устройство, размер батча и seed.

Для итогового сравнения берется точность после последней эпохи, а не лучший результат за все эпохи. В `train_seconds` не входят скачивание данных и проверка на тесте.

Команда `python plot_results.py results/20261009-151838` строит графики для отчета и сохраняет их в `assets/`. Наши эксперименты описаны в `report.md`.

Итоговые материалы: `report.md` содержит отчет, `presentation.pptx` и `presentation.pdf` содержат презентацию, `paper.pdf` содержит оригинал статьи, `results/20261009-151838/` содержит данные пяти запусков. В `train.py` находится код воспроизведения.

Для проверки стиля кода: `python -m pip install ruff`, затем `ruff format .` и `ruff check --fix .`.
